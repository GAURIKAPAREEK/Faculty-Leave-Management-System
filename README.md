Faculty Management System

A simple and responsive Faculty Management System built using HTML, CSS, and JavaScript.
This project helps manage faculty-related activities such as attendance tracking, leave management, academic calendar scheduling, and faculty records through an easy-to-use interface.

Features
Faculty Dashboard
Attendance Management
Leave Application System
Academic Calendar
Responsive UI Design
Faculty Records Management
Simple Navigation Interface
Interactive Frontend using JavaScript

Technologies Used
HTML5 – Structure of the website
CSS3 – Styling and responsive design
JavaScript – Dynamic functionality and interactions
