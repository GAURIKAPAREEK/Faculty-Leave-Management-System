Faculty Management System

A simple and responsive Faculty Management System built using HTML, CSS, and JavaScript.
This project helps manage faculty-related activities such as attendance tracking, leave management, academic calendar scheduling, and faculty records through an easy-to-use interface.

Features are Faculty Dashboard,Attendance Management,Leave Application System,Academic Calendar,Responsive UI Design,Faculty Records Management,Simple Navigation Interface,Interactive Frontend using JavaScript

Technologies Used :-
1. HTML5 – Structure of the website
2. CSS3 – Styling and responsive design
3. JavaScript – Dynamic functionality and interactions
